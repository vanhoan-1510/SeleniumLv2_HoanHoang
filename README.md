# Selenium Automation Framework

A Java-based test automation framework using Selenium, TestNG, and Allure Report.

## Tech Stack
- Java 11+
- Selenium 4
- TestNG
- Allure Report
- Maven

## Project Structure
selenium-framework/
├── framework-core/
├── framework-data/
├── framework-report/
└── test-app/

## Prerequisites
- Java 11+
- Maven 3.8+
- Chrome browser
